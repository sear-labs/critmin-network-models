# lithiumsc-experiments — ARCHIVED, merged into mineralnet-optsc-iise-2026

An archive of experimental formulations of the six-stage (mine→proc→cathode→cell→pack→recycling)
lithium supply-chain model: import/export and stockpiling variants, market-share objectives,
region-only (no-trade) variants, binary trade decisions, and incremental constraint additions.
This is the exploratory lineage that led to the current model in `mineralnet-optsc-iise-2026`.

**Status: exploratory — early phase, not yet reproducible.** Migrated from
[`searlab/SEAR_Lab`](https://github.com/searlab/SEAR_Lab) (`LithiumSupplyChain/`) and restructured
to follow [`sear-labs/code-standard`](https://github.com/sear-labs/code-standard) (Archetype A).

## ⚠ Data paths not fixed in 8 of the 12 notebooks

Unlike `mineralnet-optsc-iise-2026` and `biofuel-optsc-iise-2024`, **most of these notebooks still hardcode a Windows
path that does not exist in this repo**:

```
r'C:\Users\sxa2334\Downloads\Lithium Modeling\Code\jupyter_folder\input_csvs\New input files\...'
```

That `New input files` folder is a **larger** set than what's committed here — it includes
import/export and stockpile cost tables (`*_export_cost.csv`, `*_import_cost.csv`,
`*_stock_cost.csv` per stage) that aren't in `data/raw/input_files/`. Rewriting ~500 `read_csv`
calls across 8 notebooks without being able to execute and check each one risked silently breaking
them, so **they were carried over as-written rather than patched**. Affected:
`li-impexp-stock.ipynb`, `ufl-main-dr-jones-noinitial.ipynb`, `adding-new-constraints-adjustment.ipynb`,
`test10-only-region-no-trade-initialcons.ipynb`, `test11-no-trade-no-initialcons.ipynb`,
`test2-adding-new-constraints.ipynb`, `test3-marketshare-objective.ipynb`,
`test8-2-impexp-binary-decision.ipynb`, `test9-only-region-no-trade.ipynb`.

To fix one: locate its `New input files` folder (or rebuild the missing tables), drop it under
`data/raw/`, and point `DATA_DIR` there — same pattern as `mineralnet-optsc-iise-2026`.

`lithium-network-v4.ipynb` has no external data dependency. `marketshare-data-analysis.ipynb` and
`semifinal-data-analysis.ipynb` use Colab's interactive file-upload widget rather than a fixed
path — nothing to fix there either.
